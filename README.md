# Тариф

Установщики приложения для локальной подготовки отчётов по поездкам.

[Скачать последнюю версию](https://github.com/santicc712/taxi-app-releases/releases/latest)

Для Windows 10/11 x64 скачайте файл `Tarif-Setup-…-windows-x64.exe`. Эталонные вымышленные файлы и инструкция находятся в `Tarif-reference-example.zip` рядом с установщиком.

Начиная с версии 1.3 приложение проверяет обновления при запуске и каждые четыре часа. Ручная проверка доступна в «Настройки → Обновления приложения». После загрузки нажмите «Перезапустить и установить» и подтвердите действие. Сохранённые компании и отчёты остаются на компьютере.

В этом репозитории находятся только публичные сборки. Исходный код хранится в отдельном приватном репозитории. Рабочие документы и отчёты не публикуются.

Установщик без цифровой подписи издателя. Перед рабочим использованием необходимо проверить установку и обновление на Windows.
